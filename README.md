## Ask Subah news answers

Ask Subah uses Gemini with Google Search grounding. Create a Gemini API key in [Google AI Studio](https://aistudio.google.com/app/apikey), then add this server-only setting to `.env.local`:

```dotenv
GEMINI_API_KEY=your_key_here
```

Restart the development server after changing `.env.local`. Do not add the key to a `NEXT_PUBLIC_` variable or commit it. Without this setting, the Ask endpoint returns a setup message instead of a demo answer. Provider availability, rate limits, and account terms apply.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
